## buildEventEntrypointType

```ts
function buildEventEntrypointType(error?: ProfilerErrorOptions): ProfilerEntrypointType;
```

Builds the `event` entrypoint type with a host-supplied error classification. A handler execution synthesises a `500` response when it throws, but the status layer is **off by default** for this kind — the verdict rests on the captured exception, so `error: { exceptions: ['TimeoutError'] }` narrows it to the failures that matter when a handler throws routinely as flow control. `EVENT_ENTRYPOINT_TYPE_DEF` is the same type with the default classification.

`EventProfilerService` registers the configured type at bootstrap; you never call this yourself unless you are building a variant.

## Setup

```ts
// In the module that registers EventEmitterModule:
import { Module } from '@nestjs/common';
import { ConditionalModule } from '@nestjs/config';
import { EventEmitterModule } from '@nestjs/event-emitter';
import { EventEmitterCollectorModule } from '@eleven-labs/nest-profiler-event-emitter';

const isProfilerEnabled = (env: NodeJS.ProcessEnv) => env['PROFILER_ENABLED'] === 'true';

@Module({
  imports: [
    EventEmitterModule.forRoot(),
    ConditionalModule.registerWhen(
      EventEmitterCollectorModule.forRoot({ ignoreEvents: [/^internal\./] }),
      isProfilerEnabled,
    ),
  ],
})
export class NotificationsModule {}
```

`forRootAsync` resolves the option **values** from DI (thresholds from `ConfigService`, for instance); `enabled` stays a synchronous build-time decision, so gate per environment with `ConditionalModule.registerWhen(...)`.

```ts
EventEmitterCollectorModule.forRootAsync({
  inject: [ConfigService],
  useFactory: (config: ConfigService) => ({
    slowThreshold: config.get<number>('profiler.performance.slowThreshold'),
    capturePayload: config.get<boolean>('profiler.capturePayload'),
  }),
});
```

**Prerequisite:** `EventEmitterModule.forRoot()` from `@nestjs/event-emitter` must be registered (it provides `EventEmitter2` globally). Pass `emitterToken` when the emitter is bound to a custom token.
