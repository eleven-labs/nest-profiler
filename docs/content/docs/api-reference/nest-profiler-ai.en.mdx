## AiCaptureLevel

```ts
type AiCaptureLevel = 'none' | 'metadata' | 'redacted' | 'full';
```

How much of one kind of content reaches a stored profile. `none` keeps the figures and records
nothing of what was said, `metadata` keeps the shape (`[text omitted · 1842 chars]`), `redacted`
is the default and masks credentials and personal data, and `full` stores it verbatim with no
masking.

## AiCaptureFieldLevels

A level per content field, for the setups where one field is more sensitive than the rest.
Resolution runs from the narrowest: a field, then the group it belongs to (`prompt` covers
`instructions` and `messages`, `tools` covers the three tool fields), then `default`.
`runtimeContext` is outside that chain — the AI SDK's `runtimeContext` on a call and each tool's
`toolContext` hold the application's own state rather than what was said, so they are recorded
only when the field is named, not even by `capture: 'full'`.


## AI_PII_PATTERNS

```ts
const AI_PII_PATTERNS: readonly RegExp[];
```

The personal-data shapes the `redacted` level masks beyond the credential detectors: email
addresses, international phone numbers, IBANs and US social-security numbers. Exported so a host
can see exactly what is matched, and extend it through `redaction.patterns`.

## AiToolOrigin

```ts
type AiToolOrigin = 'local' | 'mcp' | 'provider';
```

Where a tool comes from, which decides who runs it: `local` is declared in the application's code,
`mcp` was discovered on an MCP server at runtime, and `provider` is built into the model itself (a
provider-run web search, say) and never executes in the application at all.

## AiModelPricing

What one model charges. Rates are per `per` tokens — a million by default, the unit providers
publish. A rate left out falls back to the one it refines, so a model with no cache discount and
no separate thinking rate needs only `input` and `output`.

<AutoTypeTable path="packages/nest-profiler-ai/src/ai-pricing.ts" name="AiModelPricing" />

## AiPricingTable

```ts
type AiPricingTable = Record<string, AiModelPricing>;
```

Prices by model. A key is `provider:model` (`openai:gpt-4o-mini`) or the bare model id
(`gpt-4o-mini`), matched in that order and case-insensitively. A provider arrives qualified by its
transport (`openai.responses`), and its root is tried too.

## AiPricingSource

```ts
type AiPricingSource = () => AiPricingTable | Promise<AiPricingTable>;
```

Loads a price table from wherever the prices live. Called when the module starts and, once
`pricingTtl` has passed, again in the background — never on the path of a model call.

## fetchOpenRouterPricing

```ts
function fetchOpenRouterPricing(options?: OpenRouterPricingOptions): Promise<AiPricingTable>;
```

Reads the prices of every model OpenRouter serves, ready to hand to `pricingSource`. The list is
public, so no key is needed. Model ids come back as OpenRouter writes them (`openai/gpt-4o-mini`),
which is what the AI SDK reports for a call that went through OpenRouter.

## estimateCost

```ts
function estimateCost(
  usage: AiTokenUsage | undefined,
  provider: string,
  model: string,
): number | undefined;
```

What a call cost, from its token counts and the configured prices — `undefined` when the model has
no price. Cached and thinking tokens are billed at their own rate and are already counted in the
input and output totals, so each is taken out before its rate is applied. The collector applies
this itself; call it directly only to cost something of your own.

## markMcpTools

```ts
function markMcpTools(names: readonly string[]): void;
```

Tells the collector which tool names came from an MCP server, so it can label their origin `mcp`.
Call it once after loading a server's tools.

## AI_ENTRYPOINT_TYPE

```ts
const AI_ENTRYPOINT_TYPE = 'ai';
```

The `Profile.entrypoint.type` a profiled HTTP request is promoted to once it has called a model.
