## Service

### TracerService

Injectable facade. Inject it in any provider or controller to instrument your application: open
trace spans, report errors your code caught itself, and read the identifiers of the profile in
flight. Every method is a no-op outside a profiled execution - see
[Trace spans](/docs/packages/nest-profiler/collectors#trace-spans).

<AutoTypeTable path="packages/nest-profiler/src/services/tracer.service.ts" name="TracerService" />

### TraceSpanDelegate

The handle on an open span, passed to the `span()` callback and returned by `startSpan()`.

<AutoTypeTable
  path="packages/nest-profiler/src/trace/trace-span.delegate.ts"
  name="TraceSpanDelegate"
/>

### Span

Method decorator recording a method as one span of the trace, without touching its body. Same
nesting and error marking as `TracerService.span()`, but it leaves `return` meaning what it means
and needs no injection. See
[Measuring a whole method](/docs/packages/nest-profiler/collectors#measuring-a-whole-method-span).

```ts
@Span('db.products.findAll')
async findAll(): Promise<Product[]> {
  return this.repo.findAll();
}
```

### createProfilerInstrument

Builds the `instanceDecorator` that `NestFactory` takes through its `instrument` option (Nest
`@nestjs/core` 11.1.4+). Every provider method call then becomes a span, so the trace carries the
full call tree instead of only the spans you opened by hand. **Opt-in and development-only**: it
places a Proxy on every provider instance, a cost paid whether or not the request is profiled. See
[Recording every method call
automatically](/docs/packages/nest-profiler/collectors#recording-every-method-call-automatically).

```ts title="main.ts"
import { createProfilerInstrument } from '@eleven-labs/nest-profiler';

const app = await NestFactory.create(AppModule, {
  instrument: createProfilerInstrument(),
});
```

<AutoTypeTable
  path="packages/nest-profiler/src/instrument/profiler-instrument.ts"
  name="ProfilerInstrumentOptions"
/>

`markInternal(target)` opts a provider of your own out of the recording, the same way the
profiler's own providers are; `isInternal(target)` reads that mark back.

### TraceContributor

Implemented by a collector that projects its already-collected entries onto the trace, so its
queries or outgoing calls appear as spans in the waterfall alongside the ones you opened by hand.
`entriesToSpans(entries, options)` turns a collector's already-timed entries into the `RawSpan[]`
`getTraceSpans()` must return, without re-timing anything.

<AutoTypeTable path="packages/nest-profiler/src/trace/build-trace.ts" name="TraceContributor" />

## Optional peers

Helpers for a collector package that works with a library it does not depend on.

### loadOptionalPeer

```ts
function loadOptionalPeer<T>(
  specifier: string,
  logger?: { warn(message: string): void },
): T | undefined;
function resolveOptionalPeer<T>(specifier: string): OptionalPeer<T>;
```

Loads an optional peer and tells its three outcomes apart: **loaded**, **absent** (not installed — the normal case, and silent), and **broken** (installed but its own code threw or one of its dependencies is missing). A bare `try { require(x) } catch {}` reports the last two identically, which turns a broken install into a panel that is silently missing.

`loadOptionalPeer` returns the exports, or `undefined` when the package is absent, warning through `logger` only on the broken case. `resolveOptionalPeer` returns the tagged `OptionalPeer<T>` union when you need to branch yourself.

Both recover a subpath a package's `exports` map refuses to publish — `@nestjs/core/package.json` from Nest 12 on — by reading it from the package root. For resolving _providers_ rather than modules, see `tryResolve`.
